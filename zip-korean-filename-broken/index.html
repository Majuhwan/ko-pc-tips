압축 파일 한글 이름이 깨지는 이유와 대처

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

압축 파일을 풀었는데 파일 이름이 알 수 없는 기호로 바뀌어 있는 경우가 있어요. 파일 이름을 저장하고 읽는 방식이 서로 맞지 않아서 생기는 일이 많아요. ZIP 형식의 공식 규격에서 원인의 단서를 찾고, 대처 순서까지 정리했어요.

ZIP 규격이 말하는 파일 이름 저장 방식

ZIP 형식을 정의한 PKWARE의 APPNOTE 문서는 다음과 같이 설명해요.

  • ZIP 형식은 역사적으로 IBM PC의 원래 문자 집합인 코드 페이지 437만 지원했어요. 이 집합은 MS-DOS 시절의 문자 범위로 제한돼서 다른 언어의 파일 이름을 제대로 담지 못한다고 문서가 직접 적고 있어요.
  • 이를 보완하려고 일반 목적 비트 11(언어 인코딩 플래그)이 만들어졌어요. 이 비트가 켜져 있으면 파일 이름과 주석은 UTF-8로 저장돼야 해요.
  • 비트 11이 꺼져 있으면 파일 이름은 원래의 ZIP 문자 인코딩을 따르게 돼요.

이 규격은 UTF-8 표시가 없는 이름을 어떤 문자 집합으로 읽을지까지 정하지 않아요. 그래서 UTF-8 표시 없이 한글 이름을 넣은 압축 파일은 푸는 도구가 이름을 읽는 방식에 따라 다르게 보일 수 있어요. 어떻게 처리하는지는 도구마다 달라요.

대처 순서

  1. 먼저 열려는 파일이 열리는지 확인하세요. 깨진 것이 이름뿐인지, 파일 자체가 손상됐는지 구분하는 단계예요.
  2. 압축 파일을 다시 받아 보세요. 전송 중에 생긴 문제인지 가려내는 가장 쉬운 방법이에요.
  3. 보낸 사람에게 다시 압축해 달라고 요청하세요. Apple 지원 문서도 .zip 파일에 문제가 있어 열 수 없을 때는 보낸 사람에게 다시 압축해 보내 달라고 요청하라고 안내해요. 이때 UTF-8 이름 옵션을 쓸 수 있는지 확인해 달라고 덧붙이면 좋아요.
  4. 다른 방식으로 풀어 보세요. Windows 11 버전 24H2는 ZIP, RAR, 7z, TAR 형식을 지원한다고 Microsoft가 안내해요. 같은 파일을 운영체제 기본 기능과 다른 도구로 각각 풀어 비교하면 원인을 좁힐 수 있어요. 도구에 이름 문자 집합을 고르는 옵션이 있다면 바꿔 보세요.

이미 풀었는데 이름이 이상할 때

원본 압축 파일은 지우지 말고 보관해 두세요. 풀어낸 파일이 정상적으로 열린다면 이름만 직접 바꿔도 돼요. 파일이 많다면 이름을 일일이 고치는 것보다 재압축을 요청하는 편이 빨라요.

보내는 쪽이 할 수 있는 일

  • 압축 도구에 파일 이름을 UTF-8로 저장하는 옵션이 있는지 확인해요.
  • 받는 사람이 어떤 운영체제를 쓰는지 모르면 이름을 영문과 숫자로 바꿔서 압축해요.
  • 보내기 전에 압축 파일을 다른 도구로 한 번 열어 보면 이름이 제대로 보이는지 알 수 있어요.

핵심 정리

  • ZIP은 원래 코드 페이지 437만 지원했고, UTF-8 이름은 비트 11로 표시해요.
  • 한글 이름 깨짐은 이 표시가 없는 압축 파일에서 이름을 읽는 방식이 어긋날 때 생겨요.
  • 먼저 파일이 열리는지 보고, 다시 받은 뒤 재압축을 요청해요.
  • 다른 도구로 풀어 보고, 이름 문자 집합 옵션이 있으면 바꿔 봐요.
  • 보내는 쪽은 UTF-8 이름 옵션이나 영문 이름을 써요.
