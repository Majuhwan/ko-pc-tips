Windows와 Mac에서 zip 압축하고 풀기

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

여러 파일을 하나로 묶어 보내거나 크기를 줄일 때 zip을 써요. Windows와 Mac은 모두 별도 프로그램 없이 기본 기능만으로 압축하고 풀 수 있어요.

Windows에서 압축하기

  1. 압축할 파일이나 폴더를 찾아요.
  2. 마우스 오른쪽 단추로 클릭해요.
  3. 압축된 폴더로 보내기를 선택해요. Windows 11에서는 추가 옵션 표시를 먼저 눌러야 보일 수 있어요.

같은 위치에 압축 폴더가 새로 만들어져요. 이름을 바꾸려면 오른쪽 클릭 후 이름 바꾸기를 선택하고 새 이름을 입력해요. 이미 만든 압축 폴더에 파일을 더 넣고 싶다면 그 파일을 압축 폴더로 끌어다 놓아요.

메뉴가 길게 나오면 항목 이름을 위에서부터 읽어 압축된 폴더로 보내기를 찾으세요. 이 항목은 보통 "보내기" 하위 메뉴 안에 들어 있어요.

Windows에서 풀기

  • 파일이나 폴더 하나만 꺼내려면 압축 폴더를 열고 새 위치로 끌어다 놓아요.
  • 전체를 풀려면 압축 폴더를 오른쪽 클릭하고 모두 추출을 선택한 뒤 안내를 따라요.

Mac에서 압축하고 풀기

  1. Finder 윈도우나 데스크탑에서 파일이나 폴더를 Control-클릭해요.
  2. 단축 메뉴에서 압축을 선택해요.
  3. 풀 때는 .zip 파일을 두 번 클릭해요.

항목 하나를 압축하면 원래 이름에 .zip 확장자가 붙어요. 여러 항목을 한 번에 압축하면 이름이 아카이브.zip이 돼요. 압축을 풀면 결과물이 .zip 파일과 같은 폴더에 나타나고, 원한다면 .zip 파일은 지워도 돼요.

단축 메뉴에서 항목 이름이 ""압축""으로 시작하는 줄을 고르면 돼요. 여러 개를 고른 상태에서는 "N개의 항목 압축"처럼 보일 수 있어요.

압축하기 전에 알아 둘 점

상황 설명
JPEG 사진 이미 높은 비율로 압축된 형식이라, 여러 장을 압축 폴더로 묶어도 총 크기는 원래와 비슷해요. 묶어 보내는 편리함이 장점이에요
암호화된 파일 압축 폴더에 넣으면 풀 때 암호화가 해제되어 개인 정보나 중요한 정보가 노출될 수 있어요. Microsoft는 암호화된 파일은 압축하지 말라고 안내해요
암호가 걸린 압축 파일 Windows 11 24H2의 기본 기능은 암호화된 보관 파일을 만들거나 푸는 것을 지원하지 않아요. 7-Zip이나 WinRAR 같은 타사 프로그램을 쓰라고 안내돼요
7z, RAR, TAR Windows 11 24H2는 이 형식도 푸는 것을 지원하는 것으로 안내돼요

열리지 않을 때

Mac에서 .zip 파일이 열리지 않으면 압축을 푼 항목을 담을 공간이 충분한지 확인해요. 다른 사람에게 받은 파일이라면 파일 자체에 문제가 있을 수 있으니 보낸 사람에게 다시 압축해서 보내 달라고 요청해요. 이름이 깨져 보이는 문제는 별도 글에서 다뤄요.

핵심 정리

  • Windows는 오른쪽 클릭의 압축된 폴더로 보내기와 모두 추출을 써요.
  • Mac은 Control-클릭의 압축과 .zip 두 번 클릭을 써요.
  • JPEG처럼 이미 압축된 파일은 zip으로 묶어도 크기가 거의 줄지 않아요.
  • 암호화된 파일은 압축하면 암호화가 풀릴 수 있어요.
  • 열리지 않으면 풀 공간과 파일 상태를 확인해요.
