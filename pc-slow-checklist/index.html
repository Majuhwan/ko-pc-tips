PC가 느려질 때 먼저 점검할 순서

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

PC가 갑자기 느려지면 프로그램을 마구 지우기 전에 원인을 좁혀 보는 것이 좋아요. Microsoft는 저장 공간 부족, 백그라운드에서 도는 시작 앱, 오래된 소프트웨어, 성능이 모자란 하드웨어 같은 여러 이유로 Windows 장치가 느려질 수 있다고 설명해요. 쉽고 되돌리기 쉬운 것부터 순서대로 해 보세요. 메뉴는 Windows 11 기준이에요.

한눈에 보는 순서

단계 메뉴 경로 노리는 원인
1. 업데이트 시작 > 설정 > Windows 업데이트 수정 사항과 성능 개선이 담긴 업데이트 누락
2. 맬웨어 검사 설정 > 개인 정보 & 보안 > Windows 보안 > 바이러스 & 위협 방지 CPU와 디스크를 소모하는 위협
3. 저장 공간 설정 > 시스템 > 저장소 디스크 공간 부족
4. 시작 앱 작업 관리자 > 시작 앱 부팅 때 자동 실행되는 앱
5. 열린 앱 작업 관리자 > 프로세스 많이 열린 앱과 브라우저 탭

1단계: 업데이트 확인

시작 > 설정 > Windows 업데이트에서 업데이트를 확인해요. Microsoft는 Windows 업데이트에 수정 사항과 성능 개선이 포함되는 경우가 많다고 안내해요. 업데이트가 없으면 고급 옵션 > 선택적 업데이트에 새 드라이버 같은 항목이 있는지도 봐요. 설치 과정에서 다시 시작이 필요할 수 있어요.

2단계: 맬웨어 빠른 검사

맬웨어가 CPU와 디스크 자원을 쓰면서 속도를 떨어뜨릴 수 있어요. Windows 보안 > 바이러스 & 위협 방지에서 빠른 검사를 선택해요.

3단계: 저장 공간 확인

디스크 공간이 부족하면 시스템 성능이 떨어질 수 있다고 Microsoft는 안내해요. 설정 > 시스템 > 저장소에서 남은 공간을 보고, 저장 공간 센스나 임시 파일 정리로 비워요. 자세한 순서는 C 드라이브 정리 글을 참고해요.

4단계: 시작 앱 줄이기

  1. Ctrl+Shift+Esc를 눌러 작업 관리자를 열어요.
  2. 왼쪽 메뉴에서 시작 앱을 선택해요.
  3. 자동 실행이 필요 없는 앱을 마우스 오른쪽 단추로 눌러 사용 안 함을 선택해요.

끄더라도 앱이 지워지지는 않고 시작할 때 자동으로 실행되지 않을 뿐이에요.

5단계: 열린 앱과 탭 정리, 다시 시작

앱이나 브라우저 탭이 많이 열려 있으면 PC가 느려질 수 있어요. 작업 관리자의 프로세스 탭에서 쓰지 않는 앱을 마우스 오른쪽 단추로 눌러 닫아요. 성능 탭과 시작 앱 탭에서는 자원을 많이 쓰는 항목을 볼 수 있어요. 그래도 나아지지 않으면 시작 > 전원 > 다시 시작을 선택하고, 다시 시작한 뒤에는 필요한 앱만 열어요.

여기까지 해도 느리다면

Microsoft 문서에는 더 나아간 방법도 있어요. 백그라운드 앱 권한 끄기, 시각 효과를 최상의 성능으로 조정하기, 전원 모드를 최상의 성능으로 바꾸기, 드라이브 조각 모음 및 최적화예요. 최상의 성능 옵션은 전력 소비를 늘려 노트북 배터리가 더 빨리 닳고 기기가 더 따뜻해질 수 있다고 Microsoft가 주의를 줘요. 이런 설정은 한 번에 하나씩 바꿔야 어떤 변경이 효과였는지 알 수 있어요.

핵심 정리

  • 업데이트와 맬웨어 빠른 검사부터 확인해요.
  • 디스크 공간이 부족하면 성능이 떨어질 수 있어요.
  • 작업 관리자의 시작 앱 탭에서 자동 실행을 줄여요.
  • 쓰지 않는 앱과 탭을 닫고, 안 되면 다시 시작해요.
  • 설정은 한 번에 하나씩 바꿔 효과를 확인해요.
