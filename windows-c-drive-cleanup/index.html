Windows C 드라이브 용량 확인하고 정리하는 순서

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

C 드라이브가 가득 차면 PC 성능이 떨어지거나 Windows 업데이트를 설치하는 데 문제가 생길 수 있다고 Microsoft는 안내해요. 지우기 전에 어디에 얼마나 쌓였는지부터 보고, 쉬운 것부터 순서대로 비우는 방법이에요. 메뉴 이름은 Windows 11 기준이에요. Microsoft 문서는 각 단계를 마칠 때마다 공간이 충분히 확보됐는지 확인한 뒤 다음 단계로 넘어가라고 권해요.

1단계: 남은 공간 확인하기

작업 표시줄에서 파일 탐색기를 열고 왼쪽에서 내 PC를 선택하면 드라이브별로 사용 가능한 공간이 표시돼요.

2단계: 무엇이 차지하는지 보기

  1. 시작 > 설정 > 시스템 > 저장소로 이동해요.
  2. 디스크 사용량에서 임시 파일, 앱, 문서 같은 범주별 용량을 확인해요.
  3. 이 화면의 용량 표시줄이 빨간색이면 디스크 공간이 부족한 상태예요.

범주별로 보면 앱이 많은지, 다운로드가 큰지처럼 정리 방향이 보여요.

3단계: 정리 권장 사항 사용하기

저장소 > 정리 권장 사항에서 Windows가 지워도 될 후보를 범주별로 보여 줘요.

범주 내용
임시 파일 시스템과 앱이 남긴 임시 항목
대용량 또는 사용되지 않는 파일 크기가 크거나 오래 열지 않은 파일
클라우드에 동기화된 파일 클라우드와 동기화되어 PC에도 있는 파일
사용되지 않는 앱 오래 쓰지 않은 앱

각 범주를 훑어보고 지울 항목만 체크한 뒤 정리 단추를 눌러요. 항목마다 확보할 수 있는 용량이 표시되니 큰 것부터 골라 보세요. 임시 파일과 이전 Windows 설치를 다루는 방법은 임시 파일을 비우는 글에서 따로 설명해요.

4단계: 큰 개인 파일 찾기

비디오, 음악, 사진, 다운로드 폴더에 가장 큰 파일이 있는 경우가 많아요.

  1. 파일 탐색기에서 해당 폴더를 열어요.
  2. 보기 > 세부 정보를 선택해요.
  3. 빈 곳을 마우스 오른쪽 단추로 눌러 크기 기준으로 정렬해요. 가장 큰 파일이 맨 위에 와요.

필요 없는 파일은 삭제하고, 보관할 파일은 USB 드라이브나 SD 카드 같은 외부 저장 장치로 옮겨요. 파일 탐색기에서 잘라내기를 한 뒤 외부 장치에서 붙여넣기를 하면 돼요. 외부 장치를 연결해 두면 파일을 계속 쓸 수 있고 PC 공간은 차지하지 않아요.

5단계: 휴지통 비우기

파일을 삭제해도 휴지통을 비워야 장치에서 완전히 제거되어 공간이 확보돼요. 되살릴 파일이 없는지 본 뒤 비우세요.

그래도 부족하다면

  • 새 파일을 저장할 드라이브 바꾸기: 시작 > 설정 > 시스템 > 저장소 > 고급 저장소 설정 > 새 콘텐츠가 저장되는 위치에서 콘텐츠 유형별로 저장할 드라이브를 고를 수 있어요. 공간이 더 넉넉한 드라이브가 있을 때 써요.
  • 사용하지 않는 앱 제거: 시작 > 설정 > 앱 > 설치된 앱에서 제거할 앱 옆의 기타 옵션(...)을 눌러 제거를 선택해요.
  • 외부 저장소로 업데이트하기: Windows가 기능 업데이트에 더 많은 공간이 필요하다고 알리면 외부 저장 장치를 임시로 쓸 수 있어요.

핵심 정리

  • 파일 탐색기의 내 PC에서 남은 공간을 먼저 확인해요.
  • 설정 > 시스템 > 저장소에서 범주별 사용량을 봐요.
  • 정리 권장 사항에서 지울 항목을 직접 골라 정리해요.
  • 큰 파일은 크기순으로 찾아 삭제하거나 외부 저장 장치로 옮겨요.
  • 마지막에 휴지통을 비워야 공간이 확보돼요.

참고한 공식 자료

  1. Microsoft 지원 Windows에서 드라이브 공간 확보
  2. Microsoft 지원 저장 공간 센스를 사용하여 드라이브 공간 관리
  3. Microsoft 지원 Windows에서 PC 성능을 개선하는 팁
