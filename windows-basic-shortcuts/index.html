Windows 자주 쓰는 단축키 기본 정리

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

Windows 단축키는 외우는 것보다 "이럴 때 이 키"로 묶어 두면 빨리 익혀져요. 아래는 Microsoft 지원의 바로 가기 키 문서에 나온 조합 가운데 일상에서 자주 부딪히는 상황만 골랐어요. 표의 Windows 키는 키보드의 창 모양 로고 키예요.

복사하고 붙여넣을 때

하고 싶은 일 단축키
복사 Ctrl+C
잘라내기 Ctrl+X
붙여넣기 Ctrl+V
모두 선택 Ctrl+A
일반 텍스트로 붙여넣기 Ctrl+Shift+V

Microsoft는 일부 응용 프로그램에서는 Ctrl+Shift+V가 작동하지 않을 수 있다고 안내해요. 문서에 나오는 단축키는 기본 Windows 동작이고, 프로그램에 따라 달라질 수 있어요.

실수했을 때

  • Ctrl+Z: 방금 한 작업을 취소해요.
  • Ctrl+Y: Ctrl+Z로 취소한 입력을 다시 실행해요.

창이 많이 열려 있을 때

하고 싶은 일 단축키
열려 있는 창 사이 전환 Alt+Tab
작업 보기 열기 Windows 키+Tab
바탕 화면 표시 또는 숨기기 Windows 키+D
모든 창 최소화 Windows 키+M
활성 창 최대화 Windows 키+위쪽 화살표
현재 창 닫기 Alt+F4

Alt+Tab은 Alt 키를 누른 채 Tab을 여러 번 누르면 여러 창을 차례로 넘어가요. Alt+F4를 눌렀을 때 열린 창이 없으면 종료하라는 메시지가 나타나요.

자리를 비우거나 설정을 열 때

하고 싶은 일 단축키
컴퓨터 잠금 Windows 키+L
파일 탐색기 열기 Windows 키+E
설정 열기 Windows 키+I
입력 언어 및 자판 배열 전환 Windows 키+스페이스바

프로그램이 멈췄을 때

Ctrl+Shift+Esc를 누르면 작업 관리자가 바로 열려요. 응답 없는 프로그램을 확인할 때 시작 메뉴를 거치지 않아도 돼요.

복사한 내용과 화면 캡처

  • Windows 키+V: 클립보드 기록을 열어요. Microsoft는 이 단축키를 쓰려면 시작 > 설정 > 시스템 > 클립보드에서 클립보드 기록 토글을 켜야 한다고 안내해요.
  • Windows 키+Shift+S: 스크린샷으로 캡처할 화면 영역을 고르고, 그 결과를 클립보드에 담은 다음 캡처 도구에서 열어 공유하거나 표시를 할 수 있어요.

핵심 정리

  • 복사·잘라내기·붙여넣기는 Ctrl+C, Ctrl+X, Ctrl+V예요.
  • Ctrl+Z로 취소하고 Ctrl+Y로 다시 실행해요.
  • 창 전환은 Alt+Tab, 바탕 화면 표시는 Windows 키+D예요.
  • 자리를 비울 때는 Windows 키+L, 프로그램이 멈췄을 때는 Ctrl+Shift+Esc예요.
  • Windows 키+V는 클립보드 기록을 먼저 켜야 쓸 수 있어요.
