Mac 자주 쓰는 단축키 기본 정리

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

Mac 단축키는 대부분 command 키(⌘)로 시작해요. Apple 지원 문서에 따르면 보조 키를 누른 상태에서 마지막 키를 누르는 방식이에요. 예를 들어 command-C는 command 키를 누른 채 C를 누르고 두 키를 함께 놓으라는 뜻이에요. 이 글은 Windows를 쓰다 온 사람을 기준으로, 달라지는 점 위주로 정리했어요.

Windows 키와 어떻게 대응할까

Windows Mac 메뉴에 표시되는 기호
Ctrl (복사, 붙여넣기 등) command ⌘
Alt option ⌥
Shift shift ⇧
해당 없음 control ⌃

Apple 문서는 Windows PC용 키보드를 Mac에 연결하면 option 키 대신 alt 키를, command 키 대신 ctrl 키 또는 Windows 로고 키를 누르면 된다고 안내해요.

편집 단축키는 Ctrl 자리에 command

하고 싶은 일 단축키
복사 command-C
잘라내기 command-X
붙여넣기 command-V
실행 취소 command-Z
모두 선택 command-A
저장 command-S
찾기 command-F

실행 취소 뒤에 shift-command-Z를 누르면 실행 복귀가 돼요.

창 닫기와 앱 종료는 달라요

Windows에서는 창을 닫으면 앱이 같이 끝나는 경우가 많지만 Mac은 구분해요.

하고 싶은 일 단축키
전면에 있는 윈도우 닫기 command-W
앱의 윈도우를 모두 닫기 option-command-W
현재 앱 종료 command-Q
전면 앱의 윈도우 가리기 command-H
다음으로 최근에 쓴 앱으로 전환 command-Tab
같은 앱의 윈도우 간 전환 command-억음 악센트(`)

억음 악센트 키는 키보드마다 위치가 다르지만 보통 Tab 키 위쪽, 숫자 1의 왼쪽에 있어요. 같은 앱의 윈도우를 오갈 때 쓰는 키라서, 앱을 바꾸는 command-Tab과는 쓰임이 달라요.

파일과 검색

하고 싶은 일 단축키
선택한 항목을 휴지통으로 이동 command-delete
휴지통 비우기 shift-command-delete
Spotlight 검색 필드 표시 또는 가리기 command-스페이스 바
화면 잠금 control-command-Q
스크린샷 또는 화면 기록 shift-command-5

shift-command-3, shift-command-4 키로도 스크린샷을 찍을 수 있어요.

모르는 단축키를 찾는 법

Apple 문서는 앱마다 자체 단축키가 있고, 가장 빨리 찾는 방법이 앱의 메뉴를 여는 것이라고 안내해요. 파일이나 편집 같은 메뉴를 열면 각 명령 오른쪽에 단축키가 표시돼요. 메뉴 항목에 원하는 단축키를 직접 만들 수도 있어요. 시스템 설정 > 키보드 > 키보드 단축키 > 앱 단축키에서 추가하면 돼요.

기능 키가 안 먹힐 때

Mac 키보드 맨 윗줄에는 밝기, Mission Control 같은 기능이 그려진 키가 있어요. 이 키를 F1, F2 같은 표준 기능 키로 쓰려면 fn(function) 또는 지구본 키와 함께 눌러야 해요.

핵심 정리

  • 복사·붙여넣기 같은 편집 단축키는 Ctrl 대신 command를 써요.
  • command-W는 윈도우만, command-Q는 앱 전체를 끝내요.
  • command-Tab은 앱 전환, command-억음 악센트는 같은 앱의 윈도우 전환이에요.
  • 파일을 휴지통으로 보내는 키는 command-delete예요.
  • 단축키는 앱 메뉴 오른쪽에 표시되고, 기능 키는 fn과 함께 눌러야 할 수 있어요.
