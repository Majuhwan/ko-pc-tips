Windows 임시 파일과 휴지통 안전하게 비우기

게시 2026년 10월 11일 · 공식 자료 확인 2026년 10월 11일 · 2027년 04월 다시 확인 예정

임시 파일과 휴지통은 눈에 잘 띄지 않지만 공간을 차지해요. Windows에는 이런 항목을 폴더를 뒤지지 않고 정리하는 방법이 세 가지 있어요. 필요할 때 직접 지우는 방법, 자동으로 지우는 저장 공간 센스, 디스크 정리예요. 메뉴는 Windows 11 기준이에요.

임시 파일을 직접 지우기

  1. 시작 > 설정 > 시스템 > 저장소로 이동해요.
  2. 임시 파일을 선택해요.
  3. 제거할 파일에 체크하고 파일 제거를 선택해요.

체크하기 전에 항목 설명을 읽어 보세요. 다운로드 폴더 같은 개인 파일이 목록에 들어 있으면 지금 지워도 되는지 먼저 확인해야 해요.

저장 공간 센스로 자동 정리하기

저장 공간 센스는 휴지통의 임시 파일처럼 필요 없는 항목을 자동으로 제거해 공간을 확보하는 기능이에요. 켜는 방법은 시작 > 설정 > 시스템 > 저장소에서 저장 공간 센스를 켬으로 바꾸는 거예요. Microsoft 안내를 정리하면 이래요.

항목 동작
기본 상태 기본적으로 꺼져 있어요. 공간이 부족하다는 알림이 뜨면 켜라고 안내돼요
실행 시점 기본 설정으로 켜 두면 디스크 공간이 부족할 때 실행돼요. 실행 빈도도 고를 수 있어요
휴지통 기본적으로 일정 시간이 지난 항목이 삭제돼요
다운로드 폴더, OneDrive 설정하지 않는 한 그대로 남아요
대상 드라이브 Windows가 설치된 시스템 드라이브(보통 C:)에서만 작동해요
실행 조건 로그인한 상태에서 10분 이상 온라인이 아니면 실행되지 않아요

지금 저장 공간 센스 실행을 선택하면 바로 한 번 돌려 볼 수 있어요. 휴지통과 다운로드 폴더의 삭제 기준은 저장 공간 센스 설정에서 고를 수 있어요. 다운로드 폴더에는 아직 쓸 파일이 있을 수 있으니, 켜기 전에 기준을 신중히 정하세요.

디스크 정리 도구 쓰기

시작을 선택하고 디스크 정리를 입력한 뒤 결과에서 디스크 정리를 열어요. 정리할 드라이브를 고르면 임시 파일과 시스템 파일을 삭제할 수 있어요.

이전 Windows 설치 지우기

큰 업그레이드 뒤에는 이전 버전으로 돌아갈 수 있는 파일이 남아요. 업그레이드한 지 10일이 지나지 않았다면 이전 버전의 Windows가 삭제 가능한 시스템 파일로 나열된다고 Microsoft는 안내해요. 저장소 > 임시 파일에서 이전 Windows 설치가 선택되어 있는지 확인하고 파일 제거를 누르면 돼요.

이 폴더(Windows.old)를 지우면 되돌릴 수 없고 이전 버전의 Windows로 돌아갈 수도 없어요. 업그레이드 뒤 문제가 없는지 충분히 쓴 다음에 지우세요.

정리했는데도 공간이 부족하다는 오류가 날 때

Microsoft는 추천 정리 항목으로 공간을 확보했는데도 디스크 공간 부족 오류가 난다면, Microsoft Store 앱 파일(.appx) 때문에 임시 폴더가 빠르게 찼을 수 있다고 설명해요. 해결 순서는 다음과 같아요.

  1. 시작 > 설정 > 시스템 > 문제 해결 > 기타 문제 해결사에서 Windows 스토어 앱 옆의 실행을 선택해요.
  2. Windows 로고 키+R로 실행 창을 열고 wsreset.exe를 입력해 Microsoft Store 캐시를 지워요. 빈 창이 열렸다가 약 10초 뒤 닫히면서 Store가 열려요.
  3. 기타 문제 해결사에서 Windows 업데이트 옆의 실행을 선택해요.
  4. 컴퓨터를 다시 시작하고 오류가 계속되는지 확인해요.

휴지통은 마지막에

파일을 삭제해도 휴지통을 비우기 전에는 장치에서 완전히 제거되지 않아요. 휴지통을 열어 되살릴 파일이 없는지 보고 비우세요.

핵심 정리

  • 설정 > 시스템 > 저장소 > 임시 파일에서 직접 정리할 수 있어요.
  • 저장 공간 센스는 기본으로 꺼져 있고, 켜면 시스템 드라이브만 정리해요.
  • 다운로드 폴더와 OneDrive는 설정하지 않으면 건드리지 않아요.
  • 이전 Windows 설치를 지우면 이전 버전으로 돌아갈 수 없어요.
  • 휴지통은 되살릴 파일이 없는지 보고 마지막에 비워요.

참고한 공식 자료

  1. Microsoft 지원 저장 공간 센스를 사용하여 드라이브 공간 관리
  2. Microsoft 지원 Windows에서 드라이브 공간 확보
  3. Microsoft 지원 Windows에서 PC 성능을 개선하는 팁
